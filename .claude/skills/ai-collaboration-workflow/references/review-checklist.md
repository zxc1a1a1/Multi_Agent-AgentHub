# AI 协作 Review Checklist

## 1. 范围检查

- 是否只处理用户指定任务？
- 是否只处理用户指定 Skill？
- 是否没有顺手修改其他 Skill？
- 是否没有生成未授权业务代码？
- 是否没有引入无关文件？

## 2. 阶段检查

- 是否正确识别当前阶段？
- 是否没有把 MVP 历史限制当成当前限制？
- 是否没有把 Sprint 样例写成永久硬约束？
- 是否没有把未来规划写成当前必做？

## 3. 独立性检查

- 当前 Skill 是否独立可读？
- 是否避免强依赖其他 Skill？
- 是否只在必要处说明边界？
- references 是否只补充当前 Skill？

## 4. 中文检查

- 正文是否中文？
- PATCH_NOTES 是否中文？
- MANIFEST 是否中文？
- docs/contracts 是否中文？
- 路径和技术字段是否保留必要英文？

## 5. 文件包检查

- 是否包含 `MANIFEST.md`？
- 是否包含 `PATCH_NOTES.md`？
- 是否使用仓库相对路径？
- 是否没有缓存文件？
- 是否没有隐藏敏感文件？
- 是否没有业务代码，除非用户要求？

## 6. 安全检查

- 是否没有 API key？
- 是否没有 token？
- 是否没有私密配置？
- 是否没有内部敏感提示？
- 是否没有无关个人信息？

## 7. 交付检查

- 是否提供下载链接？
- 是否说明包内文件？
- 是否说明主要改动？
- 是否说明如何使用？
- 是否说明未包含内容？
