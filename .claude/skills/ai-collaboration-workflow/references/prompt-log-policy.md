# Prompt 与决策记录规则

## 1. 记录目的

AI 协作记录用于说明：

- 为什么这样改；
- 参考了哪些资料；
- 做了哪些范围取舍；
- 哪些内容没有做；
- 后续应如何继续。

## 2. 推荐记录内容

可以记录：

- 用户目标摘要；
- 当前阶段；
- 参考文件；
- 修改范围；
- 关键决策；
- 风险；
- 验证结果；
- 后续建议。

## 3. 禁止记录内容

不得记录：

- API key；
- token；
- cookie；
- 私密凭据；
- 原始系统提示；
- 无关聊天内容；
- 不必要的长篇内部推理；
- 用户未授权公开的信息。

## 4. 记录位置

文档类交付可记录在：

- `PATCH_NOTES.md`
- `MANIFEST.md`
- `docs/contracts/*.md`
- PR 描述
- Review 报告

## 5. 表达方式

记录应面向人类开发者，简洁、可追溯、可执行。

不要把记录写成泛泛口号。
