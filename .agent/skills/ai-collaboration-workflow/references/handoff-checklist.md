# 交接 Checklist

## 1. 必须说明

交付时必须说明：

- 文件包下载位置；
- 包内包含哪些文件；
- 哪些文件用于覆盖仓库；
- 哪些文件是说明文件；
- 是否包含业务代码；
- 如何查看 diff；
- 后续建议。

## 2. 推荐交接格式

```md
已生成：
[下载链接]

包内包含：
- ...

主要变化：
- ...

使用方式：
解压到仓库根目录后查看 git diff。

未包含：
- 未修改业务代码
- 未修改其他 Skill

后续建议：
- ...
```

## 3. 禁止事项

- 不得只给 zip 不说明内容。
- 不得声称已经应用到用户仓库。
- 不得声称运行了未运行的测试。
- 不得隐藏失败或不确定事项。
- 不得继续自动做下一步。
