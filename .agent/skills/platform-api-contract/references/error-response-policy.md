# 错误响应策略

Platform API 错误必须同时满足 HTTP status 合理、业务 code 稳定、message 脱敏。

## HTTP Status

- `400`：请求格式或参数错误。
- `401`：未认证。
- `403`：无权限。
- `404`：资源不存在或不可见。
- `409`：资源状态冲突。
- `422`：语义校验失败。
- `429`：限流。
- `502`：内部下游服务不可用。
- `504`：内部下游服务超时。

## 禁止

- 把 stack trace 返回给前端。
- 把内部 URL、service token、数据库连接串返回给前端。
- 用户取消操作返回 500。
