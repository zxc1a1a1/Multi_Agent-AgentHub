# AgentHub API 错误码

本文档用于补充 `docs/contracts/openapi.yaml` 中的业务状态码约定。  
统一响应格式保持为：

```json
{
  "code": 0,
  "data": {},
  "message": "success"
}
```

错误响应统一为：

```json
{
  "code": 错误码,
  "data": null,
  "message": "错误描述"
}
```

## 状态码清单

| code | 含义 | 建议 HTTP Status |
|---|---|---|
| 0 | 成功 | 200 / 201 / 204 |
| 400001 | 参数错误 | 400 |
| 401001 | 未登录 | 401 |
| 403001 | 无权限 | 403 |
| 404001 | 资源不存在 | 404 |
| 409001 | 资源冲突 | 409 |
| 429001 | 请求过于频繁 | 429 |
| 500001 | 内部服务错误 | 500 |
| 502001 | 下游服务错误 | 502 |
| 504001 | 服务超时 | 504 |

## 使用规则

1. 错误场景下 `data` 必须为 `null`。  
2. 不允许错误时返回 `code = 0`。  
3. 不允许所有错误都返回 HTTP 200。  
4. 同一类错误在不同接口必须保持同一响应结构。  
5. 若新增错误码，必须同步更新 `openapi.yaml` 示例、前端 API Client、后端实现与测试。
