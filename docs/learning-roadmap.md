# 学习路线

## 第一阶段：Git 和仓库协作

- clone / branch / checkout / pull / push
- PR / MR
- 冲突解决
- master/dev/feature 分支模型

## 第二阶段：React 前端

- Vite + React + TypeScript
- fetch / SSE / WebSocket
- 组件拆分
- A2UI Renderer

## 第三阶段：Go 后端

- net/http
- JSON API
- SSE 流式响应
- middleware
- config / service / handler 分层

## 第四阶段：Agent 基础

- LLM 调用
- tool calling
- state / session
- 多 Agent 编排

## 第五阶段：协议

- AG-UI：前端和 Agent 后端的实时交互
- A2UI：Agent 输出声明式 UI
- A2A：Agent 与 Agent 通信
- MCP：Agent 接工具和数据

## 第六阶段：生产化

- 鉴权
- 日志
- tracing
- rate limit
- eval
- deployment
