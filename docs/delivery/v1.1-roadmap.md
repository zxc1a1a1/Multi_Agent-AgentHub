# AgentHub v1.1 Roadmap

本文档列出 v1.1 规划能力，**v1.0 不包含这些功能**。

## 优先级排序

### P0（核心能力扩展）

| 能力 | 说明 | 依赖 |
|------|------|------|
| **LLMPlanner feature flag** | 通过 `ORCHESTRATOR_PLANNER_MODE=llm` 切换 LLM 驱动计划生成 | LLM API key + 安全审查 + cost management |
| **vision-agent 服务化** | 多模态 Agent（图像理解/OCR）接入 | pkg/adk 扩展 + 第三方 OCR/视觉 API |
| **Agent Registry / AgentCard 完整化** | 动态 Agent 注册、服务发现、能力契约化 | 配置中心或 etcd/consul |

### P1（产品体验完善）

| 能力 | 说明 | 依赖 |
|------|------|------|
| **Run History UI** | 前端展示历史 Run 列表、RunStep 详情 | 前端组件设计 + API 扩展 |
| **Artifact object storage** | 大产物（代码包、图片、文档）存 S3/MinIO | 对象存储配置 + content reference 解析 |
| **Retry / fallback audit 完整化** | 记录重试次数、fallback 链路、Run metadata | Run/RunStep model 扩展 |

### P2（平台基础建设）

| 能力 | 说明 | 依赖 |
|------|------|------|
| **Multi-user auth** | JWT + RBAC 多用户认证与权限 | Auth service + database |
| **Observability dashboard** | Metrics / traces / logs 可视化 | Prometheus + Grafana 或等价方案 |
| **Production DB 可选项** | PostgreSQL / MySQL 支持（替代 SQLite） | 数据库 driver + migration 适配 |
| **More e2e tests** | 更多端到端场景（sequential、群聊、错误恢复） | CI/CD 环境 |
| **更多 Agent 服务化** | file-agent → document-agent → test-agent → security-agent 分批搬迁 | 按契约成熟度 |

## v1.0 → v1.1 升级路径

1. **不破坏 v1.0 主链路** — Gateway → Orchestrator → Agent 契约不变
2. **增量接入** — 新功能通过 feature flag / 新增 endpoint 引入
3. **SQLite → 生产 DB** — 通过 `AGENTHUB_GATEWAY_STORE` 或新环境变量切换
4. **RulePlanner → LLMPlanner** — 通过 `ORCHESTRATOR_PLANNER_MODE` 切换，RulePlanner 保留为 fallback

## 不在本 Roadmap 的范围

- 前端 UI 重写
- Agent 协议变更（保持 A2A 兼容）
- 架构边界的根本性改变（Gateway ↔ Orchestrator 分进程硬约束不变）
- 将 legacy `server/` 重新作为主路径
