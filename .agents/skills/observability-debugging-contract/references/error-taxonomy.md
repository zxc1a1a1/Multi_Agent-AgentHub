# Error Taxonomy

## 目的

定义 AgentHub 稳定错误码分类。

## 错误域

- `GATEWAY_*`
- `ORCHESTRATOR_*`
- `PLAN_*`
- `AGENT_*`
- `LLM_*`
- `ARTIFACT_*`
- `TOOL_CALL_*`
- `STREAM_*`
- `REGISTRY_*`
- `PERSISTENCE_*`
- `SECURITY_*`
- `INTERNAL_*`

## 推荐错误码

- `GATEWAY_BAD_REQUEST`
- `GATEWAY_ORCHESTRATOR_UNAVAILABLE`
- `ORCHESTRATOR_PLAN_INVALID`
- `ORCHESTRATOR_AGENT_UNAVAILABLE`
- `PLAN_SCHEMA_INVALID`
- `PLAN_CAPABILITY_UNSUPPORTED`
- `AGENT_TASK_FAILED`
- `LLM_TIMEOUT`
- `LLM_STRUCTURED_OUTPUT_INVALID`
- `ARTIFACT_NORMALIZATION_FAILED`
- `TOOL_CALL_ARGS_INVALID`
- `STREAM_CLIENT_DISCONNECTED`
- `REGISTRY_HEALTH_CHECK_FAILED`
- `PERSISTENCE_WRITE_FAILED`
- `SECURITY_REDACTION_REQUIRED`
- `INTERNAL_UNEXPECTED`

## 规则

- 错误码稳定，不随文案变化。
- 用户可见错误使用 `safeMessage`。
- 内部错误必须脱敏后进入日志。
- stack trace 不进入前端响应。
