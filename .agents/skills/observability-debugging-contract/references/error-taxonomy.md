# 错误码规则

## 1. 目的

本文定义 AgentHub 稳定错误码 taxonomy。

错误码用于用户安全提示、日志检索、告警和排障。

## 2. 通用错误码

```text
UNKNOWN_ERROR
VALIDATION_FAILED
AUTH_FAILED
PERMISSION_DENIED
TIMEOUT
CANCELLED
INTERNAL_ERROR
```

## 3. Orchestration 错误码

```text
PLAN_VALIDATION_FAILED
AGENT_NOT_FOUND
SKILL_NOT_FOUND
STRATEGY_NOT_SUPPORTED
FALLBACK_FAILED
SEQUENTIAL_DEPENDENCY_FAILED
PARALLEL_PARTIAL_FAILED
```

## 4. A2A 错误码

```text
A2A_AGENT_UNAVAILABLE
A2A_SEND_FAILED
A2A_STREAM_FAILED
A2A_TASK_CANCELLED
A2A_TASK_TIMEOUT
A2A_AGENT_CARD_INVALID
```

## 5. Artifact 错误码

```text
ARTIFACT_SCHEMA_INVALID
ARTIFACT_PERSIST_FAILED
ARTIFACT_CONTENT_REF_INVALID
ARTIFACT_PREVIEW_MAPPING_FAILED
ARTIFACT_NOT_FOUND
```

## 6. LLM 错误码

```text
LLM_PROVIDER_FAILED
LLM_RATE_LIMITED
LLM_TIMEOUT
LLM_CONTEXT_CANCELLED
LLM_STRUCTURED_OUTPUT_INVALID
LLM_FALLBACK_FAILED
```

## 7. AG-UI / Frontend 错误码

```text
AGUI_STREAM_FAILED
AGUI_EVENT_INVALID
TOOL_CALL_ARGS_INVALID
TOOL_CALL_UNKNOWN
FRONTEND_SKILL_NOT_IMPLEMENTED
```

## 8. 规则

每个错误必须包含：

```text
errorCode
safeMessage
traceId
runId
```

内部日志可包含脱敏后的 detail。

用户响应不得包含 stack trace、secret、内部路径。
