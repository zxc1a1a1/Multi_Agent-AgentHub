# 任务接收模板

本文件定义 AI 在 AgentHub 项目中接收任务时应如何整理输入。

## 1. 必填信息

推荐每个任务至少明确：

```md
## Goal
本轮要完成什么？

## Scope
允许修改哪些文件或目录？

## Context
必须参考哪些文件、链接、计划或代码？

## Constraints
不得做什么？是否只处理一个 Skill？是否必须中文？

## Output
用户要的是思路、文件包、补丁、代码实现、Review，还是测试建议？

## Done When
什么情况下算完成？
```

## 2. AI 自检问题

接到任务后，AI 应先判断：

- 用户是在要求“思考”还是“产出文件”？
- 用户是否指定了一个具体 Skill？
- 用户是否要求中文？
- 用户是否要求打包 zip？
- 用户是否允许修改业务代码？
- 当前任务是否需要参考用户上传的 Sprint / PDR / Contract？
- 是否需要联网核对最新资料？
- 是否有安全、隐私或授权边界？

## 3. 默认策略

如果用户没有明确授权代码修改，默认只生成文档或建议。

如果用户要求输出文件包，必须生成：

- `SKILL.md` 或用户指定文件；
- 必要 references；
- 必要 docs/contracts；
- `PATCH_NOTES.md`；
- `MANIFEST.md`。

## 4. 避免过度追问

如果信息足够完成一个合理版本，不应反复追问。

可以基于当前资料做最佳努力，并在交接中说明假设。
